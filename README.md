# D-Tech Business Insight 360 – Power BI Dashboard

## 📊 Project Overview

This is my first Power BI dashboard project, created as a portfolio project for a fictional computer and PC hardware company called **D-Tech**.

The goal of this project was to build an interactive **Business Insight 360 dashboard** that provides a complete view of business performance across different departments.

The dashboard brings together sales, finance, marketing, supply chain, and executive-level insights into one interactive Power BI report.

---

## 🎯 Project Objective

The main objective was to transform business data into meaningful and interactive visual insights that can help management understand:

- Sales performance
- Financial performance
- Product performance
- Customer performance
- Regional performance
- Marketing performance
- Supply chain metrics
- Forecast accuracy
- Executive-level KPIs

---

## 📌 Dashboard Views

### 🏠 Business Insight 360

The landing page provides an overview of the complete dashboard and allows users to navigate between different business areas.

### 💰 Finance View

The Finance dashboard focuses on financial performance and includes:

- Net Sales
- Gross Sales
- Cost of Goods Sold
- Gross Margin
- Operating Expenses
- Net Profit
- Year-over-Year comparison
- Sales and profit trends

### 📈 Sales View

The Sales dashboard provides insights into:

- Customer performance
- Product performance
- Regional performance
- Net Sales
- Gross Margin
- Sales trends
- Top and bottom performing products/customers

### 📢 Marketing View

The Marketing dashboard analyzes product and market performance through:

- Product performance
- Regional/market performance
- Net Sales
- Gross Margin
- Profitability metrics
- Customer/product analysis

### 🚚 Supply Chain View

The Supply Chain dashboard focuses on forecasting and operational performance, including:

- Forecast Accuracy
- Net Error
- Absolute Error
- Risk indicators
- Customer-level metrics
- Product/segment analysis

### 👔 Executive View

The Executive dashboard provides a high-level summary of business performance through:

- Revenue trends
- Gross Margin trends
- Net Profit trends
- Regional performance
- Revenue by customer
- Top products by revenue
- Executive-level KPIs

## 🧠 What I Learned

This project helped me practice the complete Power BI workflow:

**Raw Data → Data Cleaning → Data Transformation → Data Modeling → DAX → Visualization → Business Insights**

It also helped me understand how different departments can use the same business data to answer different questions.
